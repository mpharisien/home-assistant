Comment exporter depuis Myfoncia ?

  1. Connectez-vous sur myfoncia.com
  2. Allez dans Mon conseil syndical → Comptes de l'immeuble
  3. Sélectionnez Comptabilité des exercices passés ou Comptabilité de l'exercice en cours
  4. Choisissez l'exercice dans le menu déroulant
  5. Cliquez sur Exporter
  6. Importez le fichier ici — les données existantes pour cet exercice seront remplacées
