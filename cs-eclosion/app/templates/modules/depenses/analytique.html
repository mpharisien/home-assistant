ℹ️ Comment sont définis ces regroupements ?

Chaque poste est isolé selon un code Foncia fixe (type de charge ou clé de répartition), indépendamment du libellé exact utilisé par Foncia. Les données brutes restent toujours intactes en base — seule la lecture est regroupée. Ces règles pourront évoluer dans le temps sans jamais affecter les données déjà importées.
